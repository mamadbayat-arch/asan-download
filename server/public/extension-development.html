افزونه‌های داخل برنامه

برای افزودن قابلیت به موتور دانلود، از بخش «افزونه‌ها»، گزینهٔ «نصب با لینک» را بزنید و آدرس مخزن افزونهٔ سازگار را وارد کنید. نصب افزونهٔ مرورگر از مسیر جداگانه انجام می‌شود.

مبنای سازگاری این نسخه، API موتور ۱.۹ است. شمارهٔ ۲ در نام آسان دانلود به معنی سازگاری با افزونه‌های نیازمند API موتور ۲ نیست. فعلاً فهرست افزونه‌های بررسی‌شده خالی است؛ آدرس افزونه را از سازندهٔ مورد اعتماد خود بگیرید.
